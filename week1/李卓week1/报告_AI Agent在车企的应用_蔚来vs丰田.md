# AI Agent 在汽车企业的应用调查：蔚来 vs 丰田

## 一、调查范围与方法

选取 1 家中国车企（蔚来）和 1 家海外车企（丰田），统一比较“研发、卖车、售后”三个场景，每个场景找 1 个公开案例，说明“用 Agent 做什么、有什么效果”。资料由 Agent 检索并初步总结，我逐条打开原文核对，发现 4 处 Agent 说错或说过头的地方并已改正（见《信源与纠错表》）。文中方括号 `[n]` 为信源编号；所有效果数据均为企业或供应商自己披露，未经第三方审计。

## 二、蔚来：从座舱智能体走向“AI 原生组织”

- **研发**：蔚来在 2026 NIO IN 上披露，自 2023 年起围绕研发项目等经营单元（CBU）推动组织改造，纳管研发项目 CBU 超过 1800 个，对比改造前研发人效提升 13%、综合研发效率提升 35% [9][10]。一个具体用法是：世界模型 NWM 3.0 选技术路线时，由智能体同步核算算力成本、硬件投入、研发工时和长期迭代开销，筛选出适合量产装车的方案 [8]。
- **卖车**：9750 多位 Fellow（门店用户顾问）可以通过“麦宝”智能助手调用各类 Agent 处理经营和服务任务，单 Fellow 经营效率同比提升 44.5%，价值创造同比提升 8.1% [9]；新京报将其表述为“门店销售人员调用智能体后”取得的效果 [8]。
- **售后**：2024 年 11 月推送的 Banyan 3.0.0 新增“NOMI 服务管家”：一键维保、上门补胎、代驾、代泊、洗车、年检等专属服务接入车机，车主说“我的车被剐蹭了”，NOMI 会主动推荐一键维保或拨打蔚来热线 [6]。这是 2024 年发布的 6 大 NOMI 智能体之一 [7]。**效果**：未查到公开的量化数据。

整体规模上，蔚来已上线超过 7500 个企业 Agent，累计运行实例超过 290 万次 [9][11]。

## 三、丰田：分部门、借助云厂商的“点状试点”

- **研发**：动力总成开发部门搭建了多智能体系统“O-Beya”（大部屋），目前有 9 个专家 Agent（如振动 Agent、燃耗 Agent），工程师可同时选多个 Agent 提问，系统把各自回答汇总成一个答案；知识来自过往设计报告、最新法规和老工程师的手写资料，目的是在资深工程师退休前把经验传下去。自 2024 年 1 月起约 800 名工程师可用，每月使用“数百次” [1]。
- **卖车**：丰田北美（TMNA）与 Toyota Connected 为经销商销售人员做了车型信息助手，实时回答配置、版本、价格等问题，回答带引用和法律免责声明。v1 是检索增强问答（RAG），覆盖整个经销商网络，月均 7000 多次交互；但它只能回答、不能执行动作。v2 计划改为 Agent 架构，可以查询本地库存等，原定 2026 年一季度上线 [5]——**目前是否上线未查到公开证据**。
- **售后**：基于 NICE Cognigy 平台部署了 25 个以上电话/聊天 AI Agent，其中语音 Agent“E-Care”直连车载电子系统：发动机警告灯亮起时主动致电车主，车主可当场通过 AI 预约保养，同时把故障数据推送给经销商提前备件。供应商案例页称 95% 直接通过 AI Agent 完成预约、98% 的用户喜欢该服务 [4]。丰田官网也提到正用联网车辆数据做电池、刹车、轮胎等预测性保养模型 [2]。

## 五、相同点与不同点

- **相同点**：两家都把 Agent 接到企业自己的数据上（设计报告、车型库、车辆故障数据），而不是只用通用聊天机器人；都在售后环节把 Agent 和预约、到店流程连起来；效果数据也都来自企业或供应商自己披露。
- **不同点**：① **广度不同**：蔚来公布 7500+ 个 Agent 覆盖研发、制造物流、用户服务、能源，丰田公开的是几个独立项目；② **路线不同**：蔚来自研并把 AI 写进组织架构，丰田更多借助云厂商和软件供应商；③ **用户不同**：丰田的 Agent 主要服务工程师、经销商、客服等内部人员，蔚来同时面向车主（座舱）和员工；④ **可核实程度不同**：丰田案例有较多技术细节和使用量，蔚来给出了亮眼的百分比，但缺少口径说明。

## 七、结论

从公开资料看，蔚来把 Agent 用得更深：它不只做座舱里的几个智能体，而是把 7500 多个 Agent 嵌进研发、门店和能源业务，并给出了研发人效 +13% 等量化结果。丰田的做法更稳、更“点状”，O-Beya、经销商助手、E-Care 各自解决一个具体问题，细节更容易核实，但还没有看到全公司层面的数据。需要提醒的是，两家的效果数字都是企业自报，蔚来的百分比尤其缺少计算口径。我最看好“售后”场景：车辆本身就在产生故障数据，Agent 可以直接完成“发现问题—联系车主—预约到店”的闭环，效果容易衡量，对车主的安全和体验也最直接。
