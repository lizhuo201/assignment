# 第一周任务要求：调查 AI Agent 在汽车企业的应用

目标只有一个：学会用 Agent 做完一件真事 —— 会拆任务、会查资料、会检查它有没有说错。不拼难度，做完就算过关。

形式：一人一组，本周不分组，独立完成  |  周期：7 天  |  截止时间：以群通知为准

先放心：本周不用写代码、不用读长论文、不用搭复杂程序。用你顺手的 Agent 工具就行，卡住了可以问带队同学，不要自己硬扛。

## 1. 查什么：只查 2 家车企

任选 2 家车企（建议 1 家中国 + 1 家海外，例如比亚迪、蔚来、小鹏、理想、特斯拉、大众、丰田中任选），每家只看 3 个场景：从研发、生产、卖车、售后、车内座舱里任选 3 个。每家每个场景找 1 个真实案例就够了，简单说清“用 Agent 做什么、有什么效果”。查不到就写“未查到公开证据”，不许编。

## 2. 只做 4 件事

- 搜一搜：让 Agent 帮你找资料，最后留下 至少 5 条能点开的来源，其中至少 3 条来自官网、年报或主流媒体。
- 读一读、比一比：让 Agent 分别总结 2 家的做法，再帮你对比哪里一样、哪里不一样，你来判断对不对。
- 做一张对比表：把 2 家 x 3 个场景填进一张表，一眼能看出差别。表格用 Word / Excel 做即可。
- 做一张图：只做 1 张图就行，例如时间线、流程图或简单的柱状图，能说明一个结论即可。

## 3. 交什么：只交 2 样

- 报告 1 份：约 1500 字，包含对比表和那 1 张图，最后用 3-5 句话写结论：哪家做得更深、你最看好哪个场景。
- 信源与纠错表 1 页：列出至少 5 条来源链接 + 至少 2 条纠错（原说法是什么、正确说法是什么、你怎么改的）。

文件夹命名：第1周_姓名，把上面 2 样放进去即可，不用再分很多子文件夹。不用交演示，不用提交演示链接、截图或视频。

## 4. 怎么算过关

报告完整、来源真实能点开、对比表和图能看懂、纠错是真的改过 —— 做到这些就过关。

只有一条红线：不许编造来源和数据。查不到就如实写查不到，这不扣分；编了才需要重做。
