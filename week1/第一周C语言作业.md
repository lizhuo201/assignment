# 第一周：学习 C 语言基本语法、数据类型、运算符、if 语句

## 考核题目：

### 1. 三角形的类型

输入三个整数 a、b、c 表示三条边长，输出一个数字表示三角形的类型：

0 不能构成，1 普通，2 等腰，3 等边

要求：类型判断用条件运算符 ?: 完成。

```text
eg:输入：3 4 5
     输出：1
     输入：3 3 4
     输出：2
     输入：3 3 3
     输出：3
     输入：1 2 5
     输出：0
```

### 2.（选做，进度快的同学做）在三边能构成三角形的情况下，再输出它的最大角是什么角：

0 锐角，1 直角，2 钝角

```text
eg:输入：3 4 5
     输出：1
     输入：3 3 3
     输出：0
     输入：2 3 4
     输出：2
```

说明：第 1 题 3 3 3 既是等边也是等腰，注意判断的先后顺序。提交源码和运行截图。
